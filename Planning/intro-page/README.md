# 소개 페이지

대회와 기획을 그림과 함께 보는 소개 페이지입니다. `index.html` 파일 하나로 되어 있습니다.

## 보는 법

리포지토리를 받은 뒤 `index.html`을 브라우저로 열면 됩니다. 설치할 것은 없습니다. 글꼴만 인터넷에서 불러옵니다.

## 고치는 법

`index.html`을 편집기로 열어 글자를 직접 고칩니다.

| 고칠 내용 | 찾을 위치 |
|---|---|
| 대회, 제출, 평가, 기획, 팀 | 번호가 붙은 각 `<section>` (`01 · 대회` ~ `06 · 팀`) |
| 전투 화면 그림, 맵 그림 | `05 · 최종 모습` 섹션의 `<svg>` |

## 주의

- 마일스톤 일정과 통과 기준은 이 페이지에 없습니다. [GitHub 마일스톤](https://github.com/Marine-Rescue-Team/z-axis-coop-fps/milestones)에서 봅니다.
- 기획 내용은 [`../02-game-design.md`](../02-game-design.md)에도 있습니다. 한쪽을 고치면 다른 쪽도 맞춰 주세요.
