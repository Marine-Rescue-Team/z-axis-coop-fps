# 외부 에셋 목록

이 리포지토리는 공개입니다. 외부에서 가져온 에셋은 **커밋하기 전에** 아래 표에 적습니다. 표에 없는 외부 에셋은 커밋하지 않습니다.

- 재배포를 금지하는 라이선스의 에셋은 무료든 유료든 올리지 않습니다.
- AI 도구로 만든 에셋도 적습니다. 대회 제출 때 사용 도구 신고와 증빙에 그대로 씁니다.
- 직접 만든 에셋은 적지 않아도 됩니다.
