# 작업 분해(WBS) 초안

마일스톤마다 어떤 작업이 필요할지 미리 나눠 본 **참고용 초안**입니다. 티켓은 여기서 자동으로 만들어지지 않습니다. 작업자가 작업을 시작할 때 직접 티켓을 만들고, 이 목록은 빠뜨린 일이 없는지 확인하는 데 씁니다.

일정과 통과 기준은 이 문서에 적지 않습니다.

- 보는 곳: [GitHub 마일스톤](https://github.com/Marine-Rescue-Team/z-axis-coop-fps/milestones)
- 고치는 곳: [`milestones.yml`](milestones.yml) (정본)

## 일정이 밀리면 줄이는 순서

통과 기준을 날짜 안에 못 넘기면 위에서부터 차례로 줄입니다. 맵 변형 자체는 줄이지 않습니다. 평가에서 비중이 가장 큰 창의성 40%가 여기에 걸려 있습니다.

1. 난이도 단계를 하나로
2. 맵 변형 2회를 1회로
3. 보스 3명이 패턴 일부를 공유
4. 전용 서버 없이 플레이어 한 명이 방을 여는 방식 유지
