## 마일스톤은 어디서 보나

- **보기:** [GitHub 마일스톤](https://github.com/Marine-Rescue-Team/z-axis-coop-fps/milestones). 단계별 마감일, 통과 기준, 진행률이 나옵니다.
- **고치기:** `milestones.yml`만 고칩니다. GitHub 화면에서 직접 고치면 다음 반영 때 덮어써집니다.
- 일정과 통과 기준은 다른 문서에 다시 적지 않습니다.

기획이 확정되면 캐릭터 시트, 보스 시트, 맵 구간 스케치를 이 폴더에 추가합니다.
