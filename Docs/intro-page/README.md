# 소개 페이지

기획과 마일스톤을 그림과 함께 보는 소개 페이지입니다. 기획 탭과 마일스톤 탭이 `index.html` 파일 하나에 모두 들어 있습니다.

## 보는 법

리포지토리를 받은 뒤 `index.html`을 브라우저로 열면 됩니다. 설치할 것은 없습니다. 글꼴만 인터넷에서 불러옵니다.

## 고치는 법

`index.html`을 편집기로 열어 글자를 직접 고칩니다.

| 고칠 내용 | 찾을 위치 |
|---|---|
| 대회, 제출, 평가, 기획, 팀 | `id="panel-plan"` 안의 각 `<section>` |
| 전투 화면 그림, 맵 그림 | `05 · 최종 모습` 섹션의 `<svg>` |
| 일정 막대 | `id="gantt"` |
| 작업 목록(WBS) | `id="wbs"` 안의 `<details class="ms">` |
| 밀릴 때 줄이는 순서 | `id="sec-cut"` |

작업을 추가하거나 지울 때 함께 맞춰야 하는 것

- 작업 번호(예: `2.3.1`)와 단계 제목 줄의 `작업 N개` 숫자
- 담당 표시: `data-o="기획"` 값과 배지 글자를 같이 바꿉니다. 담당 필터가 `data-o` 값을 읽습니다.
- 단계 날짜를 바꾸면 일정 막대의 `data-d0`(시작일, 11/26이 0), `data-days`(일수), `style`의 `left`와 `width`(60일 기준 %)도 바꿉니다.
